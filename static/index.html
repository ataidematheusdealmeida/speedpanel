Serviços e regras

Cadastre serviços, escolha horários e defina seus critérios de qualidade.

Os testes usam a conexão do servidor. A fila executa uma medição por vez. Agendamentos começam desativados; ative cada serviço após revisar seus horários.

Configurações do monitor

As datas no painel usam o fuso configurado. Os campos de filtro usam a hora local do seu navegador. O CSV usa UTC. A limpeza do histórico é executada a cada hora.

Como adicionar outros serviços

Sites diferentes precisam de integrações diferentes. Use “Site personalizado” para definir os seletores de início, conclusão e resultados; ou “API JSON” para importar medições de uma API existente. As métricas personalizadas devem retornar Mbps, ms e %.

Uma URL sozinha não informa como iniciar um teste ou interpretar seus resultados. Falhas e métricas não disponíveis aparecem no histórico, sem valores inventados. Ookla permite escolher servidor e interface; os testes em navegador usam a rota padrão do contêiner.

Configurar serviço

5 campos: minuto, hora, dia, mês, dia da semana. Ex.: “0 8,12,18 * * *” às 08h, 12h e 18h. “*/30 * * * *” a cada 30 minutos. Horários do fuso configurado.

Regras de qualidade

Zero desativa o limite. Resultados fora dos limites recebem uma sinalização no histórico. Se um serviço não mede determinada métrica, a regra correspondente fica marcada como indisponível.

Integração personalizada · seletores e caminhos JSON

Site personalizado: uma lista de seletores CSS para clicar em ordem, um seletor visível somente ao concluir, e um objeto de seletores dos resultados. API JSON: caminhos separados por ponto; números já em Mbps, ms e %. Sem executar comandos ou scripts arbitrários.
